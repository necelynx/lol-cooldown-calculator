>> Notes on Rank Estimation

Non-ultimate abilities (Q/W/E) don't have a fixed rank at a given level — it depends on which order a player levels them in. This calculator estimates ranks using the standard "max one ability at a time" leveling convention:

  1. Level 1-3: one point into each of Q/W/E, in the champion's typical priority order.
  2. From level 4 on: keep maxing the highest-priority ability first, then the second, then the third.
  3. The Ultimate (R) always ranks up at levels 6, 11 and 16 when available.

The "typical priority order" for each champion was pulled from current aggregate skill-order data on u.gg, Mobalytics and op.gg (majority vote across sources where they disagreed). If your build maxes a different ability first, use the rank dropdown next to each ability to override the estimate manually — the cooldown updates instantly.
